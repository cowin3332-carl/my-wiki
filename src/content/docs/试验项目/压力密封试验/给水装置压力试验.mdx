# 给水装置压力试验

## 一、测试目的

验证铁道客车及动车组**给水装置**在额定工作压力和最大工作压力下的耐压强度和密封性能，确保在正常和异常工况下无泄漏、无损坏。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| TB/T 1720-2017 第5.2章 | 铁道客车及动车组给水装置 压力试验 |

## 三、测试方法

| 项目 | 内容 |
|------|------|
| 压力介质 | 清洁水或标准指定介质 |
| 测试压力范围 | 0.2 MPa ~ 0.63 MPa |
| 保压时间 | ≥3 min |
| 密封检查 | 所有接头、阀体、焊缝、密封面 |
| 判定准则 | 无泄漏、无压降越限、无可见变形 |


## 四、常见失效模式

- [ ] 连接处泄漏 (螺纹/法兰/卡套)
- [ ] 密封件挤出、划伤
- [ ] 焊缝/壳体裂纹
- [ ] 压力保持不合格
