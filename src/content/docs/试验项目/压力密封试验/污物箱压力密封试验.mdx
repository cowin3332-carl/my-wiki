# 污物箱压力密封试验

## 一、测试目的

验证铁道客车及动车组集便装置**污物箱**在额定工作压力下的**密封性**和**强度**，确保在运行和驻车状态下无泄漏、无变形。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| TB/T 3338.2-2023 第6.9章 | 铁道客车及动车组集便装置 污物箱压力密封试验 |

## 三、测试方法

| 项目 | 内容 |
|------|------|
| 测试设备 | 压力气源、压力变送器、气压管路、注水/注液系统 |
| 保压时间 | ≥30 min |
| 压力范围 | 按 TB/T 3338.2 规定 |
| 判定准则 | 压降不超过标准限值/无可见泄漏 |


## 四、常见失效模式

- [ ] 焊缝/接口微漏
- [ ] 密封圈/垫老化或安装不当
- [ ] 箱体变形
- [ ] 压力保持不达标
