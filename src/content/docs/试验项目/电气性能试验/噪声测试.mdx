# 噪声测试

## 一、测试目的

噪声测试用于测量产品在运行状态下的**声压级**，评估噪声水平是否符合标准和设计要求，适用于轨道交通集便装置等设备的噪声验证。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| TB/T 3338.2-2023 第6.6章 | 铁道客车及动车组集便装置 噪声测试 |

## 三、测试参数

| 参数 | 范围 |
|------|------|
| 测量范围 | 30 dB ~ 130 dB |
| 频率计权 | A 计权/线性 |
| 测试环境 | 半消声室/消声室/现场 (背景噪声 ≤20 dB(A)) |
| 测量参数 | 声压级 (SPL)、频谱、声功率级 |


## 四、测试方法

```
1. 环境噪声测量 → 2. 安装样品 → 3. 运行工况设置
                                   ↓
    6. 数据处理 ← 5. 多点测量 ← 4. 传声器布置
```

## 五、限制说明

- 仅适用于 **集便装置** (TB/T 3338.2 专用)
- 量程 30~130 dB，超出需特殊传声器/前置放大器
- 测试环境要求背景噪声低
