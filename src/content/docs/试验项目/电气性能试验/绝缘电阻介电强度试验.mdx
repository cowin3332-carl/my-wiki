# 绝缘电阻试验 / 介电强度(耐压)试验

## 一、测试目的

绝缘电阻试验用于测量电气设备的绝缘电阻值，评估绝缘材料的性能；介电强度(耐压)试验用于验证电气设备在施加高压时的绝缘耐受能力，确保电气安全。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 25119-2021 第12.2.10章 | 轨道交通 机车车辆电子装置 绝缘试验 |
| TB/T 3338.2-2023 第6.2/6.3章 | 铁道客车及动车组集便装置 绝缘电阻/介电强度 |
| TB/T 3456-2016 第5.8章 | 动车组用截断塞门 绝缘耐压试验 |
| TB/T 1720-2017 第5.1.6章 | 铁道客车给水装置 电气绝缘及耐压试验 |

## 三、关键参数

| 测试项目 | 参数范围 |
|----------|----------|
| 绝缘电阻 | 测试电压 ≤1000V (DC)，测量电阻 ≤10 GΩ |
| 介电强度/耐压 | 测试电压 0~10 kV (AC/DC) |


## 四、常见失效模式

- [ ] 绝缘电阻低于标准要求
- [ ] 耐压试验击穿
- [ ] 漏电流超标
- [ ] 绝缘材料表面爬电
