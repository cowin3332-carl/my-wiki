# 给水装置电气绝缘及耐压试验

## 一、测试目的

验证铁道客车及动车组给水装置的**电气绝缘性能**，包括绝缘电阻测量和耐压试验，确保产品电气安全。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| TB/T 1720-2017 第5.1.6章 | 铁道客车及动车组给水装置 电气绝缘及耐压试验 |

| TB/T 1720 | [解读 →](/标准解读/tb-t/tb-t-1720-2017) | [原文 →](/标准原文/tb-t/tb-t-1720-2017) |

## 三、测试方法

| 项目 | 内容 |
|------|------|
| 绝缘电阻测量 | 使用兆欧表测量绝缘电阻值 |
| 耐压试验 | 工频耐压/直流耐压，按标准规定电压和时间 |
| 判定标准 | TB/T 1720-2017 规定的绝缘电阻下限值、耐压值、漏电流限值 |


## 四、限制说明

- **仅适用于给水装置** (TB/T 1720 专用)
- 具体电压/电阻值需查阅 TB/T 1720-2017 标准全文
