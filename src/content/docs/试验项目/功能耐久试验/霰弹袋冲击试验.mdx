# 霰弹袋冲击性能试验

## 一、测试目的

霰弹袋冲击试验用于验证**钢化玻璃**的抗冲击性能，通过标准霰弹袋冲击测试评估玻璃破碎后的安全状态，确保产品符合安全玻璃标准要求。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 15763.2-2025 第5.7章 | 建筑用安全玻璃 第2部分：钢化玻璃 霰弹袋冲击性能 |

## 三、测试方法

| 步骤 | 要求 |
|------|------|
| 样品准备 | 按标准规定尺寸、厚度、边缘状态 |
| 冲击体 | 霰弹袋：质量 45 kg ±0.5 kg，填充铅弹 |
| 冲击高度 | 按玻璃厚度/类别分级 (通常 1200 mm) |
| 判定准则 | 破碎后颗粒度、最大碎片重量、无大块锋利碎片 |


## 四、常见失效模式

- [ ] 破碎后大块锋利碎片
- [ ] 碎片颗粒度过大
- [ ] 碎片数量不足
- [ ] 冲击未破坏 (过度安全)
