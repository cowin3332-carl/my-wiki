# 集便装置性能试验

## 一、测试目的

验证铁道客车及动车组**集便装置**的各项功能性能，包括冲洗、排放、密封、控制、防溢流等，确保产品满足 TB/T 3338.2 标准要求。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| TB/T 3338.2-2023 第6.13、6.19~6.27章 | 铁路客车及动车组卫生间 集便装置 |

## 三、性能试验子项

| 章节 | 试验项目 | 说明 |
|------|----------|------|
| 6.13 | 冲洗性能试验 | 验证冲洗效果、用水量、冲洗时间 |
| 6.19 | 排放性能试验 | 验证排放流量、排放时间、残留率 |
| 6.20 | 密封性能试验 | 验证工作/非工作状态密封 |
| 6.21 | 真空度保持试验 | 验证真空系统保压能力 |
| 6.22 | 控制系统功能试验 | 验证自动/手动控制、故障报警 |
| 6.23 | 防溢流/防倒灌试验 | 验证异常工况保护 |
| 6.24 | 液位/真空度显示试验 | 验证传感器精度 |
| 6.25 | 通风/除臭性能试验 | 验证通风量、除臭效率 |
| 6.26 | 冲洗液添加/消耗试验 | 验证添加系统、消耗率 |
| 6.27 | 综合运行可靠性试验 | 长周期模拟运行、故障注入 |
