# 紧固件防松检查

## 一、测试目的

验证关键螺栓/螺母的**防松措施完整性**和**扭矩符合性**，确保电气控制柜等设备在运行中不会因振动导致紧固件松动。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 32595-2016 第8.9章 | 铁道客车及动车组用电气控制柜 紧固件防松检查 |

## 三、检查内容

| 检查项目 | 典型内容 | 验证方法 |
|----------|----------|----------|
| 防松件完整性 | 开口销、止动垫圈、自锁螺母、胶粘剂、钢丝锁固 | 目视 + 手工拨动 |
| 扭矩复核 | 关键螺栓扭矩值 | 扭矩扳手复测、标记对齐 |
| 防松措施有效性 | 锁紧装置安装正确性、无脱落/失效 | 目视 + 功能验证 |
| 标记/防篡改 | 扭矩标记 (油漆/记号笔) 完好 | 目视对比 |
