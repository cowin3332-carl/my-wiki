# 耐久性 / 开关门功能试验

## 一、测试目的

验证城市轨道车辆客室侧门的**耐久性**和**开关门功能**，确保在长期使用中保持稳定的开关动作、安全保护和功能可靠性。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 30489-2024 第6.6.4章 | 城市轨道车辆客室侧门 耐久性 |
| GB/T 30489-2024 第6.7.2章 | 城市轨道车辆客室侧门 开、关门功能 |

## 三、测试内容

| 测试项目 | 典型内容 | 关键参数 |
|----------|----------|----------|
| 耐久性 | 循环开关次数、故障率、动作时间稳定性、磨损检查 | 循环频率、总次数 (≥500,000次) |
| 开、关门功能 | 手动/自动开关、防夹保护、紧急解锁、开关门时间 | 防夹力 ≤150N，开门 ≤3s，关门 ≤4s |


## 四、常见失效模式

- [ ] 门机构磨损导致动作异常
- [ ] 防夹功能失效
- [ ] 紧急解锁卡滞
- [ ] 开关门时间超差
- [ ] 密封条磨损漏风
