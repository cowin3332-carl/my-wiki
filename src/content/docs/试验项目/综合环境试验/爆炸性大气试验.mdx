# 爆炸性大气试验 (GJB 150.13A)

## 一、测试目的

爆炸性大气试验旨在验证装备在含有**易燃易爆混合气体**（如油气、粉尘等）的环境中工作时，是否具有防止引起环境爆炸的能力（本质安全），以及在设备内部发生爆炸时，外壳是否具有足够的强度防止爆炸火花扩散。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GJB 150.13A | 军用装备实验室环境试验方法 第 13 部分：爆炸性大气试验 |
| GB/T 3836 | 爆炸性环境（系列标准） |
| MIL-STD-810H | Method 511.7 Explosive Atmosphere |

## 三、试验分类

1. **工作安全性（程序一）**：验证设备在正常工作或预期故障（如打火、过热）时，是否会引燃外部的易燃混合气体。
2. **防爆完整性（程序二）**：在设备内部注入爆炸性混合气体并引爆，验证外壳是否能承受内部压力且不泄露火焰或高温碎片。

## 四、典型试验气体

通常使用 **正己烷 (n-hexane)** 与空气按特定比例混合，模拟最易引燃的爆炸性环境。对于特殊环境，可使用丙烷、氢气或航空燃油油气。

## 五、物理影响与危险点

- **电气火花**：开关、继电器、电刷产生的电弧点燃环境。
- **表面高温**：大功率元器件表面温度超过混合气体的引燃温度。
- **静电释放**：非金属外壳静电积聚导致的瞬间放电。
- **机械火花**：金属部件高速摩擦产生的热点。

## 六、试验流程

1. **环境标定**：确保试验箱内混合气体的浓度处于最易爆炸的范围内。
2. **海拔模拟**：根据任务场景模拟不同高度下的气压，因为气压会改变混合气体的爆炸限值。
3. **功能激活**：在混合气体中频繁操作设备开关、调整负载，诱发潜在点火源。
4. **内部点火（仅程序二）**：通过火花塞手动引爆设备内部气体。

## 七、评定准则

- [ ] **无外部引燃**：试验过程中外部环境未发生爆炸
- [ ] **防爆完整性**：对于程序二，设备外壳未破裂且未向外传导火焰
- [ ] **功能维持**：试验后检查主要电气性能是否依然符合要求
