# 流体污染试验 (GJB 150.26A)

## 一、测试目的

流体污染试验用于确定装备在整个寿命周期内，由于**偶尔接触或长期暴露于各类流体**（如燃料、液压油、清洁剂、除冰液等）中，其物理性能、机械性能及电气性能是否发生不可逆的恶化。

## 三、常用试验流体类别

- **燃料类**：JP-5, JP-8 航空煤油，普通汽油/柴油。
- **润滑油类**：发动机油、齿轮油。
- **液压液类**：各类军用/航空级液压油。
- **溶剂与清洁剂**：酒精、异丙醇、特种精密清洗液。
- **除冰/防冰液**：乙二醇、丙二醇基液体。


## 四、试验方式

1. **间歇接触**：通过喷洒、刷涂或短时间浸渍，模拟偶尔溅落。
2. **长期暴露**：在特定温度下浸渍较长时间，模拟渗漏或持续浸润环境。

## 五、理化影响

- **溶胀与软化**：橡胶密封圈、塑料外壳吸收流体导致尺寸改变或硬度下降。
- **溶解与脱落**：表面标识、油漆涂层被溶剂溶解脱落。
- **脆化与开裂**：流体导致材料内部添加剂析出（塑化剂流失），导致脆裂。
- **电性能变化**：流体渗入接插件内部，导致绝缘性能丧失或接触不良。

## 六、试验流程

1. **预热处理**：部分流体需在加热状态下（如模拟发动机热油溅落）进行测试。
2. **流体施加**：将选定的流体均匀施加于样品表面。
3. **存放阶段**：在规定温度（常温或高温）下存放 8h 至 24h。
4. **清理与检查**：擦除多余流体，进行性能复测。

## 七、评定项

- [ ] **质量/体积变化**：测量橡胶、塑料件在污染前后的形变量
- [ ] **附着力测试**：检查油漆及标识是否起泡、脱落
- [ ] **硬度测试**：评估非金属材料的物理强度退化情况
