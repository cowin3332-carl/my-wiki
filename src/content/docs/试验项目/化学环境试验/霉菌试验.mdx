# 霉菌试验 (GJB 150.10A)

## 一、测试目的

霉菌试验用于评估装备在**湿热、富营养环境**下，材料对霉菌侵蚀的耐受能力。主要考核霉菌生长对材料性能的降解、外观的影响以及分泌物对电子电路的腐蚀作用。

## 三、常用菌种

通常使用 5 种或更多标准混合菌种，以保证试验覆盖不同材料的易感性：
- **黑曲霉** (Aspergillus niger)
- **黄曲霉** (Aspergillus flavus)
- **绳状青霉** (Penicillium funiculosum)
- **土曲霉** (Aspergillus terreus)
- **球毛壳霉** (Chaetomium globosum)


## 四、物理与电气效应

1. **材料降解**：霉菌分解有机材料（如天然橡胶、皮革、部分塑料），导致材料变脆、断裂。
2. **电气短路**：霉菌菌丝具有导电性，在湿热条件下易导致 PCB 板焊点间短路。
3. **光学性能**：菌丝覆盖镜头、观察窗，导致透光率下降或成像模糊。
4. **代谢产物腐蚀**：霉菌排出的有机酸会腐蚀金属基材及涂层。

## 五、试验条件

- **温度**：+28°C 至 +30°C。
- **相对湿度**：90% RH 以上。
- **持续时间**：**28 天**（常规周期）或 **84 天**（评估材料结构完整性）。

## 六、评定标准 (等级划分)

| 等级 | 描述 | 详细定义 |
|-----|-----|---------|
| 0 级 | 无生长 | 显微镜下未见霉菌生长 |
| 1 级 | 痕迹生长 | 仅显微镜下可见少量生长 |
| 2 级 | 轻微生长 | 肉眼可见散在生长，覆盖率 &lt; 10% |
| 3 级 | 中度生长 | 明显生长，覆盖率 10% - 50% |
| 4 级 | 严重生长 | 密集生长，覆盖率 > 50% |

## 七、注意事项

1. **无菌操作**：接种前需确保箱体环境及样品表面无非试验菌污染。
2. **营养对照**：需同步放入营养对照条（如棉布条），确保菌种活性正常。
3. **清洗禁忌**：试验后如需检测功能，不得擦拭表面霉菌，以免人为改变结果。
