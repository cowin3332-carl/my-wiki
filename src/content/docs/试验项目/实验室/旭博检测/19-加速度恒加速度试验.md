# 19 加速度/恒加速度试验

> **统一名称**：加速度试验 / 恒加速度试验 / 离心机试验 / Constant Acceleration Test / Centrifuge Test
> **核心能力**：
> - **军用装备/专用设备**：离心机式，单边最大负载 100 kg，总载荷 1000 kg，恒加速度范围 (20~1000) m/s²，安装半径 2250 mm，最大回转半径 2500 mm
> - **军用计算机**：同 GJB 150.15A 参数
> - **可靠性鉴定**：振动部分推力 ≤50 kN (见 14/21)
> **涉及大类**：2个 | **涉及检测对象**：3+ | **主要标准**：GJB 150.15A、GJB 150.15、GJB 322A、GJB 899A 等

## 离心机 vs 振动台 加速度能力对比

| 参数 | 离心机 (恒加速度) | 振动台 (正弦/随机) |
|------|------------------|-------------------|
| **加速度类型** | 恒定 (静态/准静态) | 动态 (交变) |
| **最大加速度** | 1000 m/s² (约 100g) | 980 m/s² (约 100g) / 1470 m/s² (炮击) |
| **频率** | 0 Hz (DC) | 2~2000 Hz / 1~2000 Hz (炮击) |
| **载荷能力** | 总 1000 kg | 8000 kg (+16000 kg 辅助) |
| **安装空间** | 半径 2250/2500 mm | 台体面积限制 |
