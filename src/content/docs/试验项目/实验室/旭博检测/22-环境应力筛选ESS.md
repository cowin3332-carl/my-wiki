# 22 环境应力筛选 (ESS)

> **统一名称**：环境应力筛选 / ESS / Environmental Stress Screening / HASS (高加速应力筛选)
> **核心能力**：容积 ≤1.0 m³，温度 (-60~+150)℃，温度变化速率 ≤10.8 ℃/min，频率 (1~4000) Hz，加速度 980 m/s²，负载 ≤2000 kg
> **涉及大类**：1个 (七、专用设备) | **涉及检测对象**：1 | **主要标准**：GJB 1032A-2020

## ESS 核心能力参数

| 参数项 | 规格范围 | 备注 |
|--------|----------|------|
| **箱体容积** | ≤1.0 m³ | 小箱，适合电子模块/板卡 |
| **温度范围** | -60℃ ~ +150℃ | 宽温域 |
| **温度变化速率** | ≤10.8 ℃/min | 极快速率，HASS 级 |
| **振动频率** | 1 Hz ~ 4000 Hz | 超标准 2000 Hz，含高频 |
| **振动加速度** | 980 m/s² (约 100g) | 标准级 |
| **最大负载** | ≤2000 kg | 中等载荷 |
| **不含服务** | 筛选方案编制、故障分析、纠正措施 | **仅提供设备/环境，不含工程服务** |

## ESS vs HASS vs 传统筛选 对比

| 项目 | 传统 ESS (GJB 1032) | HASS (高加速) | 本实验室能力 (GJB 1032A) |
|------|-------------------|--------------|------------------------|
| **温度范围** | -55~+125℃ | -100~+200℃ (超规) | -60~+150℃ |
| **温变速率** | ≤10 ℃/min | ≤60 ℃/min | ≤10.8 ℃/min (接近 HASS) |
| **振动频率** | 2~2000 Hz | 2~5000 Hz (或更高) | **1~4000 Hz** (超标准) |
| **振动加速度** | 30~50g | 50~100g | **980 m/s² = 100g** (HASS 级) |
| **筛选周期** | 长 (小时~天) | 短 (分钟~小时) | 按标准流程 |
| **工程服务** | 含方案/分析/纠正 | 含方案/分析/纠正 | **不含**方案/分析/纠正 |
