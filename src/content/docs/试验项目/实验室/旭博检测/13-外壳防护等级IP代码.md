# 13 外壳防护等级 (IP代码)

> **统一名称**：外壳防护等级 / IP代码 / IP防护 / Degrees of Protection / IP Rating
> **核心能力**：
> - **防固体异物 (IP1X~IP6X)**：IP1X~IP6X，容积 ≤72 m³，载荷 ≤5000 kg
> - **防水 (IPX1~IPX8)**：IPX1~IPX8，IPX7/IPX8 浸水深度 ≤1.5 m，容积 ≤72 m³，载荷 ≤5000 kg
> - **轨道专用**：IP54 (电气控制柜)、IP65 (截断塞门)
> - **军用/专用**：IP1X~IP6X、IPX1~IPX8 (浸水 ≤1.5m)

## IP等级能力矩阵

| IP代码 | 防护内容 | 测试方法要点 | 适用对象典型 | 关键限制 |
|--------|----------|--------------|--------------|----------|
| **IP1X** | 防 ≥50mm 固体异物 | 试验球直径 50mm | 电工电子、电力变流器、集便装置、驱动电机 | 容积 ≤72m³，载荷 ≤5000kg |
| **IP2X** | 防 ≥12.5mm 固体异物 | 试验指/球直径 12.5mm | 同上 | 同上 |
| **IP3X** | 防 ≥2.5mm 固体异物 | 试验钢丝直径 2.5mm | 同上 | 同上 |
| **IP4X** | 防 ≥1.0mm 固体异物 | 试验钢丝直径 1.0mm | 同上 | 同上 |
| **IP5X** | 防尘 (粉尘不影响运行) | 粉尘箱，抽真空/常压 | 同上 + 电气控制柜 (IP5X部分) | 同上 |
| **IP6X** | 完全防尘 | 粉尘箱，抽真空，无粉尘进入 | 同上 + 截断塞门 (IP6X) | 同上 |
| **IPX1** | 防垂直滴水 | 滴水箱，1mm/min，10min | 电工电子、电力变流器、集便装置、驱动电机、电气电子设备 | 同上 |
| **IPX2** | 防倾斜15°滴水 | 滴水箱，倾斜15°，3mm/min | 同上 | 同上 |
| **IPX3** | 防喷水 (60°锥) | 摆管/喷淋，10L/min | 同上 | 同上 |
| **IPX4** | 防溅水 (全方向) | 摆管/喷淋，10L/min，免除挡板 | 同上 | 同上 |
| **IPX5** | 防冲水 (喷嘴6.3mm) | 喷嘴6.3mm，12.5L/min，3min | 同上 | 同上 |
| **IPX6** | 防强冲水 (喷嘴12.5mm) | 喷嘴12.5mm，100L/min，3min | 同上 | 同上 |
| **IPX7** | 短时浸水 | 浸水深度 1m，30min | 同上 + 电力变流器、集便装置 (浸水 ≤1.5m) | 浸水深度 ≤1.5m |
| **IPX8** | 持续潜水 | 压力/时间由协商，>IPX7 | 同上 | 浸水深度 ≤1.5m |
| **IP54** | 防尘+防溅水 | IP5X + IPX4 | 电气控制柜 | 同上 |
| **IP65** | 完全防尘+防冲水 | IP6X + IPX5 | 截断塞门 | 同上 |
