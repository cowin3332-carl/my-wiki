## 运输试验典型内容 (GB/T 14710 第4章 / ASTM D4169 / ISTA)

| 测试序列 | 典型项目 | 目的 | 关键参数 |
|----------|----------|------|----------|
| **1. 预处理** | 温湿度调节 | 环境平衡 | 温度/湿度/时间 |
| **2. 振动** | 随机/正弦振动 | 模拟车辆/航空振动 | PSD/频谱、时长、方向 |
| **3. 冲击/跌落** | 自由跌落/倾倒/冲击 | 模拟搬运/装卸冲击 | 高度、姿态、面/棱/角 |
| **4. 压力/堆码** | 静压堆码 | 模拟仓储/车辆堆垛 | 力值、时长、变形 |
| **5. 低气压** | 高度模拟 | 模拟航空货舱 | 气压、时长 (可选) |
| **6. 后检查** | 外观/功能/性能复测 | 验证运输后完好性 | 全功能检测 |

## 医用电器运输试验 (GB/T 14710 第4章) vs 包装运输 (ASTM/ISTA)

| 对比项 | 医用电器运输 (GB/T 14710) | 包装件运输验证 (ASTM D4169/ISTA) |
|--------|--------------------------|----------------------------------|
| **测试对象** | **裸机/整机** (含包装) | **包装件** (含内装物) |
| **载荷限制** | ≤100 kg | 按包装件重量 (可更大) |
| **振动谱** | 标准规定/合同 | DC13 随机振动谱 (卡车/铁路/航空) |
| **跌落高度** | 标准规定 | 按 ISTA 1A/2A/3A 等级 (不同高度) |
| **堆码** | 不单独列出 | E1 堆码 (2000 kg/24h 等) |
| **判定** | 功能/性能/安全全检 | 外观/内装物完好/功能抽检 |
