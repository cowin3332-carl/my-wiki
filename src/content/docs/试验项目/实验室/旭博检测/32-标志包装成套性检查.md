## 检查内容细分

| 方法 | 检查项目 | 典型内容 |
|------|----------|----------|
| **方法202 成套性检查** | 零部件清单核对 | 按装箱单/技术文档逐项核对 |
| | 备品备件/工具清单 | 专用工具、随机备件、易损件 |
| | 技术文档齐套 | 说明书、合格证、检验报告、图纸清单 |
| | 配套设备完整性 | 控制柜、电缆、管路、仪表等 |
| **方法203 检查标志和包装** | 铭牌/标牌 | 产品型号、出厂编号、生产日期、额定参数 |
| | 警示/指示标识 | 高压、接地、流向、操作警示 |
| | 包装完整性 | 箱体完好、缓冲材料、防潮/防锈措施 |
| | 运输标识 | 起吊点、重心、防震、防雨、此面向上 |
| | 防护措施 | 防锈油、干燥剂、真空包装、氮气保护 |
