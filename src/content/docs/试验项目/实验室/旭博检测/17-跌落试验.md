# 17 跌落试验

> **统一名称**：跌落试验 / 自由跌落 / 包装跌落 / Drop Test / Free Fall Test
> **核心能力**：
> - **电工电子/道路车辆**：跌落高度 ≤1.5 m，载荷 ≤50 kg
> - **军用计算机/内燃机电站**：跌落高度 ≤1.5 m (1500 mm)，载荷 ≤300 kg
