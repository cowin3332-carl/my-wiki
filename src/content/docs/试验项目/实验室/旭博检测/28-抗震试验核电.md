# 28 抗震试验 (核电)

> **统一名称**：抗震试验 / 核电厂安全级电气设备抗震鉴定 / Seismic Qualification Test
> **核心能力**：单轴振动试验，推力 ≤350 kN，频率 2~2000 Hz，加速度 ≤980 m/s²，位移 ≤76 mm p-p，载荷 ≤8000 kg (+16000 kg 辅助)
> **涉及大类**：1个 (五、核电) | **涉及检测对象**：1 (核电厂安全级电气设备) | **主要标准**：GB/T 13625、HAF J0053、GB 50011

## 限制条件汇总（必读）

| 限制类型 | 涉及对象 | 具体限制 |
|----------|----------|----------|
| **仅单轴** | 所有核电抗震标准 | **不做多轴/三轴同步**，如需三轴需特殊确认 |
| **仅核电安全级** | GB/T 13625/HAF/GB 50011 | 仅限核电厂安全级电气设备，非核电产品不适用 |
| **参数同通用振动台** | 推力/频率/加速度/位移/载荷 | 可复用标准 350kN 大型振动台 |
| **鉴定大纲驱动** | GB/T 13625 | 试验条件 (RRS/TRS、阻尼、持续时间) 按鉴定大纲 |
