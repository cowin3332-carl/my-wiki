# 09 砂尘试验

> **统一名称**：砂尘试验 / 沙尘试验 / 防尘试验 / Dust and Sand Test
> **核心能力**：
> - **电工电子**：恒定气压法 La2 (GB/T 2423.37/IEC 60068-2-68)
> - **道路车辆/军用/方舱**：风速 ≤29 m/s，砂尘浓度 (2~4) g/m³ (标准) 或 1.1±0.25 ~ 10.6±7 g/m³ (方舱)，容积 ≤1~3 m³
> **涉及大类**：4个 | **涉及检测对象**：6+ | **主要标准**：GB/T 2423.37、IEC 60068-2-68、GB/T 28046.4?、GJB 150.12A、RTCA DO-160G、GJB 2093A/6109 等
