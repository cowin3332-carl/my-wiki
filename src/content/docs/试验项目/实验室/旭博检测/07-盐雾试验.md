## 关键能力参数

| 参数项 | 规格范围 | 备注 |
|--------|----------|------|
| **箱体容积** | ≤72 m³ | 全系列统一上限 |
| **盐雾类型** | 中性盐雾 (NSS) | 全系列支持 |
| | 交变盐雾 (循环) | 仅电工电子产品 (GB/T 2423.18/IEC 60068-2-52) |
| | 酸性盐雾 (AASS/CASS) | 标准支持但文档未明确列出 (GB/T 2423.17/ISO 9227 含) |
| **盐溶液浓度** | 5% NaCl (NSS) | 标准要求 |
| **箱内温度** | 35℃ ±2℃ (NSS) | 标准要求 |
| **沉降率** | 1~2 mL/(80cm²·h) | 标准要求 |
| **pH 值** | 6.5~7.2 (NSS) | 标准要求 |
