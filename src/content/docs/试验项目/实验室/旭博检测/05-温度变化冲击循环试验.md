# 05 温度变化/冲击/循环试验

> **统一名称**：温度变化试验 / 温度冲击试验 / 温度循环试验 / 温度梯度试验 / 高低温冲击 / Thermal Shock / Temperature Cycling / Temperature Change
> **核心能力**：
> - **温度变化 (两箱/风道切换)**：-60℃~+150℃，变化速率 ≤10℃/min (-55℃~+85℃)，容积 ≤72m³ (大箱) / ≤10m³ / ≤1m³
> - **温度冲击 (两箱/提篮式)**：-55℃~+125℃ (≤1.12 m³) / -70℃~+150℃ (≤1 m³, 10.8℃/min)
> - **温度循环/梯度**：容积 ≤72 m³
> **涉及大类**：5个 | **涉及检测对象**：12+ | **主要标准**：GB/T 2423.22、IEC 60068-2-14、GB/T 28046.4、GB 38031、GJB 150.5A、RTCA DO-160G、GJB 322A、GJB 2093A/6109 等

## 限制条件汇总（必读）

| 限制类型 | 涉及对象/标准 | 具体限制 |
|----------|---------------|----------|
| **不测试验 Nc** | GB/T 2423.22、IEC 60068-2-14 | 仅测 Na、Nb，不测 Nc (单箱法/渐变法) |
| **仅特定客户/产品** | GJB 150.5-1986 (旧版军标) | 仅用于特定客户的特殊要求 |
| **箱体容积分级** | 所有标准 | 不同容积对应不同温度范围和速率，选对箱体 |
| **两箱法 vs 提篮式** | Na/Nb vs 冲击 | Na/Nb 是风道/两箱切换；冲击是提篮快速移动，速率差异极大 |
| **三/四综合集成** | 三综合/四综合/可靠性鉴定 | 温度只是其中一环，需振动台/湿度/气压联合 |
