# 04 交变湿热试验

> **统一名称**：交变湿热试验 / 湿热循环试验 / 交变湿热 (12h+12h循环) / Damp Heat Cyclic / Test Db
> **核心能力**：温度 +20℃~+85℃，湿度 20%~98% RH，容积 ≤72 m³，12h+12h循环
> **涉及大类**：5个 | **涉及检测对象**：10+ | **主要标准**：GB/T 2423.4、IEC 60068-2-30、GB/T 14710、GB/T 28046.4、GJB 150.9A/4.6/367A/322A/DO-160G/GJB 6109/GJB 1488A 等

## 关键能力参数汇总

| 参数项 | 规格范围 | 备注 |
|--------|----------|------|
| **温度范围** | +20℃ ~ +85℃ | 全系列一致 |
| **湿度范围** | 20% RH ~ 98% RH | 全系列一致 |
| **循环模式** | 12h 高温高湿 + 12h 低温低湿 | 标准 Db 循环 |
| **箱体容积** | ≤72 m³ | 大箱统一上限 |
| **循环次数** | 按标准/产品要求 (通常 2~10 循环或更多) | 各标准不同 |
