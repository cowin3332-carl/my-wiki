# 01 低温试验

> **统一名称**：低温试验 / 低温贮存试验 / 额定工作低温试验 / Cold Test
> **核心能力**：温度 ≥ -65℃，容积 ≤72 m³ (大箱)；≤1 m³ (小箱，-65℃~+150℃)
> **涉及大类**：7个 | **涉及检测对象**：15+ | **主要标准**：GB/T 2423.1、IEC 60068-2-1、GB/T 14710、GB/T 28046.4、GJB 150.4A、RTCA DO-160G 等

## 关键能力参数汇总

| 参数项 | 规格范围 | 备注 |
|--------|----------|------|
| **最低温度** | -65℃ | 全系列通用下限 |
| **大箱容积** | ≤72 m³ | 6m×4m×3m 或等效 |
| **小箱容积** | ≤1 m³ | 可达 -65℃~+150℃ |
| **中箱容积** | ≤3.9 m³ | 部分标准区分 |
| **温度均匀度** | 标准未明确，按各标准要求 | GB/T 2423.1 等有规定 |
| **降温速率** | 标准未明确 | 部分标准有要求 (如 DO-160) |
| **测试功能** | 仅环境暴露，不含通电性能测试 | 多项标注「不测：性能试验」 |
