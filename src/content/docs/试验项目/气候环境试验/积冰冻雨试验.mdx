# 积冰/冻雨试验 (GJB 150.22A)

## 一、测试目的

本试验用于评估装备在经历**冻雨或在含冰雾的水气环境**中，由于表面积冰导致的性能劣化。主要考核积冰带来的额外载荷、动作机构卡滞以及由于冰层导致的无线电传输衰减。

## 三、试验参数

- **积冰厚度**：
    - 轻型：6mm
    - 中型：13mm
    - 重型：37mm 或 75mm (模拟极端环境)
- **水雾温度**：-10°C 左右（确保水滴触碰表面立即结冰）。
- **降水速率**：可调，以模拟不同强度的冻雨。


## 四、物理效应

1. **动作受限**：雷达天线旋转受阻、控制舵面卡死、门窗无法开启。
2. **结构损坏**：巨大的冰载荷导致支架弯曲或断裂。
3. **电气性能**：冰层改变了天线的介电常数，导致驻波比恶化。
4. **安全隐患**：结冰导致梯子、平台打滑，增加人员风险。

## 五、试验流程

1. **降温**：将试验箱和样品降温至 0°C 以下。
2. **喷淋结冰**：均匀喷洒冷水雾，直到样品表面形成目标厚度的均匀冰层。
3. **功能操作**：在结冰状态下尝试操作活动部件，记录受阻情况。
4. **除冰评估**：评估使用标准除冰工具或化学除冰剂的效率。

## 六、评定项

- [ ] **结构考核**：支架、杆塔在冰载下的结构完整性
- [ ] **机构考核**：可动部件是否卡死，所需的启动力矩是否超标
- [ ] **除冰效能**：除冰过程是否会对设备表面造成二次损伤
