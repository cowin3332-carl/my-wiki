# IP防护等级试验 (外壳防护等级 IP代码)

## 一、测试目的

IP防护等级试验用于验证外壳对**固体异物**和**水**侵入的防护能力，确定产品的防护等级代码 (IPXX)，确保产品在预期使用环境中的可靠性。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 4208 | 外壳防护等级 (IP代码) |
| IEC 60529 | Degrees of protection provided by enclosures (IP Code) |
| GB/T 30038 | 道路车辆 电气电子设备防护等级 (IP代码) |
| GB/T 28046.4 | 道路车辆 电气及电子设备环境条件和试验 第4部分 第7章 |

## 三、IP代码含义

| 代码位置 | 含义 | 等级范围 |
|---------|------|---------|
| **第一位数字** | 防固体异物/防人员接触 | IP0X ~ IP6X |
| **第二位数字** | 防水 | IPX0 ~ IPX8 (IPX9K) |

## 四、防固体异物等级 (IP1X~IP6X)

| IP等级 | 防护内容 | 试验方法要点 |
|--------|----------|--------------|
| IP1X | 防 ≥50mm 固体异物 | 试验球直径 50mm |
| IP2X | 防 ≥12.5mm 固体异物 | 试验指/球直径 12.5mm |
| IP3X | 防 ≥2.5mm 固体异物 | 试验钢丝直径 2.5mm |
| IP4X | 防 ≥1.0mm 固体异物 | 试验钢丝直径 1.0mm |
| IP5X | 防尘 (粉尘不影响运行) | 粉尘箱，抽真空/常压 |
| IP6X | 完全防尘 | 粉尘箱，抽真空，无粉尘进入 |

## 五、防水等级 (IPX1~IPX8)

| IP等级 | 试验类型 | 典型参数 |
|--------|---------|---------|
| IPX1 | 垂直滴水 | 1mm/min，10min |
| IPX2 | 倾斜15°滴水 | 倾斜15°，3mm/min |
| IPX3 | 淋水 (60°锥) | 摆管/喷淋，10L/min |
| IPX4 | 溅水 (全方向) | 摆管/喷淋，10L/min，免除挡板 |
| IPX5 | 喷水 (喷嘴6.3mm) | 12.5L/min，3min |
| IPX6 | 强烈喷水 (喷嘴12.5mm) | 100L/min，3min |
| IPX7 | 短时浸水 | 1m水深，30min |
| IPX8 | 持续潜水 | 压力/时间协商，>IPX7 |

## 六、组合等级示例

| IP代码 | 防护内容 | 典型应用 |
|--------|----------|---------|
| IP54 | 防尘+防溅水 | 电气控制柜 |
| IP65 | 完全防尘+防冲水 | 截断塞门、户外设备 |
| IP67 | 完全防尘+短时浸水 | 车载电子、军用装备 |
| IP68 | 完全防尘+持续潜水 | 深水设备、特种装备 |
