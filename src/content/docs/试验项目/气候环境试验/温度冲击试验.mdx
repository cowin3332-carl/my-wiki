# 温度冲击试验 (GJB 150.5A)

## 一、测试目的

温度冲击试验旨在确定产品在**极短时间内经历极端温度剧烈变化**（冷热交替）环境下的适应能力。主要用于诱发产品内部结构因热胀冷缩不一致而产生的机械应力失效。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GJB 150.5A | 军用装备实验室环境试验方法 第 5 部分：温度冲击试验 |
| GB/T 2423.22 | 环境试验 第 2 部分：试验方法 试验 N：温度变化 |
| MIL-STD-810H | Method 503.7 Temperature Shock |

## 三、试验设备

- **两箱法（提篮式）**：样品在高温箱和低温箱之间通过机械机构快速切换。
- **三箱法**：包含高温区、低温区和常温区，通过气流切换实现冲击。
- **转换时间**：通常要求在 **1 分钟** 内完成。

## 四、试验条件

| 参数项目 | 典型要求 |
|---------|---------|
| 高温端温度 | +70°C, +85°C 或更高 |
| 低温端温度 | -40°C, -55°C 或更低 |
| 转换时间 | ≤ 1 min |
| 暴露时间 | 每端 1h-4h（根据样品热时常数确定） |
| 循环次数 | 3 次、5 次、10 次或更多 |

## 五、物理效应与失效模式

- **密封失效**：密封胶脱落、封装开裂导致水汽进入。
- **机械结构损坏**：材料脆裂、应力疲劳、紧固件松动。
- **电气故障**：焊点开裂、PCB 走线断裂、参数漂移。
- **光学性能**：精密光学器件的透镜开裂或涂层剥落。

## 六、试验流程

1. **预处理**：将样品放入试验箱，进行外观和功能检查。
2. **冷热循环**：
    - 在低温端达到稳定并保持规定时间。
    - 快速切换至高温端（< 1min）。
    - 在高温端达到稳定并保持规定时间。
    - 快速切换回低温端。
3. **循环重复**：按照要求的次数重复上述过程。
4. **最后检测**：恢复后进行详细的功能和外观检测。

## 七、评定方法

- [ ] 宏观检查：外壳开裂、密封件变形、涂层起泡
- [ ] 电气检查：通电运行是否正常，有无间歇性故障
- [ ] 内部检查：对于关键产品，需切片观察焊点疲劳情况
