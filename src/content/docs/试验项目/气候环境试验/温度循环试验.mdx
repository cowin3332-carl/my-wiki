# 温度循环试验

## 一、测试目的

温度循环试验用于评估产品承受**温度快速变化**的能力，检验由于温度变化引起的膨胀、收缩、弯曲等机械应力对产品结构和性能的影响。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 2423.22 | 电工电子产品环境试验 试验 N：温度变化 |
| IEC 60068-2-14 | Environmental testing - Test N: Change of temperature |
| GJB 150.5A | 温度冲击试验 |
| MIL-STD-810H | Method 503.6 Temperature Shock |

## 三、试验类型

### 1. 温度循环（慢速变化）

- 温度变化速率：≤ 3°C/min
- 用于模拟自然环境温度变化
- 每个温度点保持时间较长

### 2. 温度冲击（快速变化）

- 温度变化速率：≥ 15°C/min（两箱法可达瞬态转换）
- 用于评估极端温度骤变影响
- 转换时间短，热应力更大

## 四、典型试验条件

### 条件示例

| 参数 | 条件 A | 条件 B | 条件 C |
|-----|-------|-------|-------|
| 低温 (°C) | -25 | -40 | -55 |
| 高温 (°C) | +55 | +70 | +85 |
| 保持时间 | 30min | 30min | 30min |
| 循环次数 | 10 | 20 | 50 |
| 转换时间 | ≤5min | ≤1min | 瞬态 |

## 六、试验设备

| 设备类型 | 特点 | 适用场景 |
|---------|------|---------|
| 单箱式 | 一个工作室，空气循环换温 | 温度循环试验 |
| 两箱式 | 冷热两个工作室，吊篮转换 | 温度冲击试验 |
| 三箱式 | 冷热+室温，可减少结露 | 高标准要求 |

## 七、常见失效模式

- [ ] 焊点疲劳开裂
- [ ] 元器件引线断裂
- [ ] PCB 分层、翘曲
- [ ] 外壳接缝开裂
- [ ] 涂层起泡、剥落
- [ ] 密封失效
- [ ] 接触不良

## 八、评定方法

试验后进行以下检测：

1. **外观检查** - 目视或放大镜观察有无裂纹、变形
2. **尺寸检查** - 测量关键配合尺寸
3. **电气检测** - 导通、绝缘、功能测试
4. **X 光检测** - 查看内部焊点、封装情况

## 九、注意事项

1. **温度范围选择**应基于产品实际使用环境
2. **保持时间**应确保样品内部温度达到稳定
3. **转换时间**越短，热应力越大
4. **循环次数**根据产品可靠性要求确定

### 限制条件汇总（温度循环/变化/梯度）

| 限制类型 | 涉及对象/标准 | 具体限制 |
|----------|---------------|----------|
| **不测试验 Nc** | GB/T 2423.22、IEC 60068-2-14 | 仅测 Na、Nb，不测 Nc (单箱法/渐变法) |
| **仅特定客户/产品** | GJB 150.5-1986 (旧版军标) | 仅用于特定客户的特殊要求 |
| **箱体容积分级** | 所有标准 | 不同容积对应不同温度范围和速率，选对箱体 |
| **两箱法 vs 提篮式** | Na/Nb vs 冲击 | Na/Nb 是风道/两箱切换；冲击是提篮快速移动，速率差异极大 |
| **三/四综合集成** | 三综合/四综合/可靠性鉴定 | 温度只是其中一环，需振动台/湿度/气压联合 |
