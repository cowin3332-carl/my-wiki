# 气体腐蚀试验

## 一、测试目的

气体腐蚀试验模拟产品在大气中存在的**二氧化硫 (SO2)、硫化氢 (H2S)、二氧化氮 (NO2) 和氯气 (Cl2)** 等腐蚀性气体环境下的耐受能力。主要用于考核接触点和连接件的腐蚀情况。

## 二、适用范围

适用于电子元器件、电连接器、接触点、涂镀层及金属材料。

## 四、试验条件选择

### 1. 气体组分
- 单一气体（如 SO2）
- 混合气体（SO2 + H2S + NO2 + Cl2）

### 2. 环境参数
- **温度**：通常为 25°C 或 30°C
- **湿度**：70% - 80% RH
- **浓度**：ppb 或 ppm 级别

## 五、试验程序

1. **预处理**：样品清洗与干燥。
2. **浓度标定**：确保试验箱内气体浓度稳定达到目标值。
3. **暴露阶段**：将样品放入试验箱，持续通入混合气体。
4. **后处理**：取出样品，必要时进行轻微清洗。
5. **性能评价**。

## 六、评定方法

- [ ] 接触电阻：测量接触点在试验前后的电阻变化
- [ ] 表面形貌：观察是否有腐蚀产物、变色、点蚀
- [ ] 机械性能：连接器的插拔力是否发生显著变化

## 七、注意事项

1. **安全性**：相关气体多有毒且有腐蚀性，试验设备必须具备完善的废气处理系统。
2. **气流均匀性**：确保箱内气流分布均匀，避免样品遮挡。
3. **湿度控制**：湿度对腐蚀速率影响极大，需精确控制。
