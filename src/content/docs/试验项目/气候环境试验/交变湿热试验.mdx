# 交变湿热试验

## 一、测试目的

交变湿热试验旨在确定电工电子产品在**温度循环变化、表面产生凝露**的高湿条件下使用和贮存的适应性。相比恒定湿热，交变湿热更容易导致呼吸效应，加速水分进入产品内部。

## 二、适用范围

适用于可能在潮湿环境中使用，且经历温度变化导致凝露形成的电子产品、元器件及材料。

## 三、核心标准

| 标准号 | 标准名称 |

| GB/T 2423.4 | 电工电子产品环境试验 第 2 部分：试验方法 试验 Db：交变湿热（12h+12h 循环） |

## 四、试验条件选择

### 1. 温度与湿度

典型的交变循环包含：
- **上限温度**：+40°C 或 +55°C
- **相对湿度**：93% ± 3% (高温阶段)
- **下限温度**：+25°C

### 2. 循环次数

常用循环次数：2, 6, 12, 21, 56 次。

## 五、试验程序

1. **初始检测**：记录初始性能参数。
2. **升温阶段**：在 3 小时内将温度升至上限，湿度升至 95% 以上。
3. **高温高湿阶段**：保持至循环开始后的 12 小时。
4. **降温阶段**：在 3-6 小时内将温度降至 25°C，湿度保持在 80% 以上。
5. **低温高湿阶段**：保持至 24 小时循环结束。
6. **恢复与最后检测**。

## 六、评定方法

- [ ] 电气性能：绝缘电阻下降、介电强度降低
- [ ] 腐蚀现象：金属部件生锈、涂层剥落
- [ ] 物理性能：材料溶胀、机械强度下降
- [ ] 功能检查：控制电路失效或误动作

## 七、注意事项

1. **凝露控制**：降温阶段的凝露是试验的关键应力。
2. **凝结水处理**：箱内顶部的冷凝水不得滴落在样品上。
3. **样机通电**：通常在非通电状态下进行，若通电需注意由于发热可能抑制凝露的产生。
