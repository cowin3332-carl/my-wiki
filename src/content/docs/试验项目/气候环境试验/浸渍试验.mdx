# 浸渍试验 (GJB 150.14A)

## 一、测试目的

浸渍试验旨在确定产品在**全部或部分浸没在水中**（如涉水行驶、越野运输或意外掉入水中）时的密封完整性，以及在浸没状态下的工作适应性。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GJB 150.14A | 军用装备实验室环境试验方法 第 14 部分：浸渍试验 |
| GB/T 2423.38 | 电工电子产品环境试验 试验 R：水 (试验 Re: 浸水) |
| MIL-STD-810H | Method 512.6 Immersion |

## 三、试验等级与条件

| 试验参数 | 常用要求 |
|---------|---------|
| **浸没深度** | 顶部离水面 0.15m 或 1m (取决于产品尺寸) |
| **水温要求** | 水温应与样品温度有一定温差（诱发呼吸效应） |
| **暴露时间** | 通常为 30 分钟或更长 |

## 四、物理效应

- **水汽侵入**：由于压力差或密封不严导致水分进入内部电路。
- **呼吸效应**：当热的设备突然进入冷水中，内部空气体积收缩产生负压，将水吸入。
- **结构损坏**：深水浸没导致的静水压力可能挤压外壳变形。

## 五、试验程序

1. **初始检测**：确认外观完整及功能正常。
2. **温差处理**（关键）：加热样品使温度高于水温 10°C~20°C，以模拟最严酷的呼吸效应。
3. **浸没阶段**：将样品浸入规定深度的水槽。
4. **观察记录**：观察是否有气泡冒出。
5. **恢复与最后检测**：擦干表面，检查内部是否有水痕，复测功能。

## 六、评定方法

- [ ] **内部检查**：开壳检查是否有水分、水滴或受潮迹象
- [ ] **绝缘电阻**：测量电路对地绝缘电阻是否大幅下降
- [ ] **功能验证**：检查电气及机械功能是否受损
