# 外观/目视/尺寸/公差检查

## 一、测试目的

通过目视和测量仪器验证产品**外观质量**、**关键尺寸**和**形位公差**是否符合图纸和技术条件要求。

## 三、检查项目

| 检查大类 | 典型内容 |
|----------|----------|
| 外观/目视 | 表面缺陷、划伤、变形、焊接外观、涂层完整性 |
| 尺寸/公差 | 关键尺寸、配合公差、形位公差、安装尺寸 |
| 标志/铭牌 | 铭牌内容、警示标识、CE/CCC标志、制造日期 |
| 包装/运输 | 包装完整性、防护等级、防震/防潮 |
| 成套性/清单 | 零部件清单核对、备品备件、技术文档齐套 |
