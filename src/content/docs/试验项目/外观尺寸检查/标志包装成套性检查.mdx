# 标志检查 / 包装检查 / 成套性检查

## 一、测试目的

按 GJB 1488A 标准验证军用内燃机电站的**标志完整性**、**包装防护**和**成套性**，确保交付产品标识清晰、包装完好、附件齐全。

## 二、核心标准

| 标准号| 标准名称 |
|--------|---------|
| GJB 1488A-2020 方法202 | 军用内燃机电站 成套性检查 |
| GJB 1488A-2020 方法203 | 军用内燃机电站 检查标志和包装 |

## 三、检查内容

| 方法 | 检查项目 | 典型内容 |
|------|----------|----------|
| 方法202 成套性检查 | 零部件清单核对 | 按装箱单/技术文档逐项核对 |
| | 备品备件/工具清单 | 专用工具、随机备件、易损件 |
| | 技术文档齐套 | 说明书、合格证、检验报告 |
| 方法203 标志和包装 | 铭牌/标牌 | 型号、编号、生产日期、额定参数 |
| | 警示/指示标识 | 高压、接地、流向、操作警示 |
| | 包装完整性 | 箱体完好、缓冲材料、防潮/防锈 |
| | 运输标识 | 起吊点、重心、防震、防雨 |
