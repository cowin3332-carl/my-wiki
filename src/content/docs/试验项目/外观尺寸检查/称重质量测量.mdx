# 称重/质量测量

## 一、测试目的

通过称重设备测量产品实际**重量/质量**，验证是否符合设计规格和标准要求。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 25122.1-2018 第4.5.3.3章 | 机车车辆用电力变流器 称重 |
| GB/T 32595-2016 第8.8章 | 铁道客车及动车组用电气控制柜 称重测试 |
| TB/T 1720-2017 第5.1.1章 | 铁道客车给水装置 水箱有效容量测试 |
| GJB 1488A-2020 方法204 | 内燃机电站 质量测量 |

## 三、测试参数

| 参数 | 范围 |
|------|------|
| 最大称重量程 | 10 t (10,000 kg) |
| 分度值/精度 | 通常 1~5 kg (10t 量程) |
| 称重方式 | 地上衡/吊秤/平台秤 |


## 四、限制说明

- 最大称重 ≤10 t，超过需外协
- 仅测重量/质量，不含重心/惯量测量
- 水箱容量通过注水称重法测定
