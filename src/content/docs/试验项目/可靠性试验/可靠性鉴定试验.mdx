# 可靠性鉴定试验 (RQT)

## 一、测试目的
可靠性鉴定试验（Reliability Qualification Test）用于验证装备在规定条件下，其可靠性特征值（如 MTBF）是否符合技术指标要求。是定型阶段的关键环节。

## 二、核心标准
- **GJB 899A**：可靠性鉴定和验收试验

## 三、试验剖面
根据受试设备任务剖面（Mission Profile）综合确定的环境应力谱。
