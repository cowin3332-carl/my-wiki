# 抗震试验 (核电)

## 一、测试目的

抗震试验用于核电厂安全级电气设备的**抗震鉴定**，验证设备在地震环境下的结构完整性和功能可靠性，确保核电站在地震工况下的安全运行。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 13625-2018 | 核电厂安全级电气设备抗震鉴定 |
| HAF J0053-1995 | 核设备抗震鉴定试验指南 |
| GB 50011-2016 | 建筑抗震设计规范 |

## 三、试验方法

### 试验类型

| 类型 | 说明 |
|------|------|
| **单轴振动** | X/Y/Z 轴向分别进行，按鉴定大纲要求的响应谱 (RRS/TRS) 驱动 |

### 典型参数

| 参数 | 范围 |
|------|------|
| 推力 | ≤350 kN |
| 频率范围 | 2 Hz ~ 2000 Hz |
| 最大加速度 | ≤980 m/s² |
| 最大位移 (p-p) | ≤76 mm |
| 载荷能力 | ≤8000 kg (+辅助支撑 16000 kg) |


## 四、核电抗震 vs 通用振动/轨道振动

| 项目 | 核电抗震 | 通用振动 | 轨道振动 |
|------|----------|----------|----------|
| 轴向 | **仅单轴** | 单轴/三轴 | 三轴 |
| 推力 | ≤350 kN | ≤350 kN | ≤350 kN |
| 频率 | 2~2000 Hz | 2~2000 Hz | 2~500 Hz |
| 载荷 | ≤8000 kg (+16000 kg) | ≤8000 kg | ≤8000 kg (+16000 kg) |

## 五、常见失效模式

- [ ] 结构件变形、开裂
- [ ] 紧固件松动
- [ ] 电气连接失效
- [ ] 继电器误动作
- [ ] 功能中断
