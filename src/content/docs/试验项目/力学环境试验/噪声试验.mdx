# 噪声试验 (GJB 150.17A)

## 一、测试目的

噪声试验（声振试验）用于确定装备在承受**高强度声学环境**（如喷气发动机噪声、火箭发射噪声或高速气流湍流）时的适应性。主要评估声波引起的结构振动对轻质、高表面积元器件的影响。

## 三、典型场景

1. **喷气飞机近场噪声**：模拟发动机喷口附近的极端声压环境。
2. **火箭发射声场**：模拟起飞阶段产生的宽带随机声振环境。
3. **高速飞行湍流噪声**：模拟超音速飞行时表面边界层产生的气动噪声。


## 四、物理效应

- **声诱发振动**：轻质薄板结构（如天线罩、太阳能电池板）的共振破坏。
- **电子元件失效**：声波直接耦合到 PCB 板导致元器件松动或参数漂移。
- **材料疲劳**：极高频次的微幅振动导致精细结构的疲劳裂纹。
- **声学干涉**：干扰传感器及麦克风的正常工作。

## 五、试验参数

- **声压级 (SPL)**：通常在 140dB 至 165dB 甚至更高。
- **频率范围**：通常覆盖 20Hz 至 10000Hz。
- **持续时间**：模拟实际任务剖面的时间（如发射阶段 120s）。

## 六、试验设备

- **混响室**：产生均匀、全方向性的声场（适用于整机测试）。
- **行波管**：产生单方向、高强度的声场（适用于小部件或表面材料测试）。

## 七、评定方法

- [ ] **外观检查**：检查轻质薄板、蜂窝结构有无分层或开裂
- [ ] **功能测试**：重点关注精密电子元器件在声场暴露后的工作稳定性
- [ ] **模态对比**：试验前后进行模态测试，判断结构特性是否发生重大改变
