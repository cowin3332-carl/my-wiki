# 振动冲击组合试验 (轨道交通专用)

## 一、测试目的

振动冲击组合试验用于评估轨道交通车辆设备在**振动+冲击联合环境**下的适应性，按 IEC 61373 / GB/T 21563 进行振动和冲击的同步或序列测试，考核产品结构强度和功能可靠性。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| IEC 61373:1999/2010 | 铁道应用 机车车辆设备 冲击和振动试验 |
| BS EN 61373:2010 | Railway applications - Rolling stock equipment - Shock and vibration tests |
| GB/T 21563-2018 | 轨道交通 机车车辆设备 冲击和振动试验 |

## 三、试验参数

### 振动参数

| 参数 | 范围 |
|------|------|
| 频率范围 | 2 Hz ~ 500 Hz (轨道专用) |
| 加速度 | ≤980 m/s² (峰值) |
| 位移 (p-p) | ≤76 mm |
| 载荷 | ≤8000 kg (+辅助支撑 16000 kg) |

### 冲击参数

| 参数 | IEC 61373:1999 | IEC 61373:2010 / EN 61373 |
|------|---------------|--------------------------|
| 加速度 | ≤300 m/s² | ≤500 m/s² |
| 脉冲宽度 | ≤30 ms | 3~30 ms |
| 速度变化量 Δv | ≤3.44 m/s | ≤3.44 m/s |
| 载荷 | ≤5000 kg | ≤5000 kg |


## 四、试验程序

```
1. 初始检测 → 2. 安装样品 → 3. 安装传感器
                             ↓
   6. 最后检测 ← 5. 振动+冲击组合 ← 4. 按类别选谱
```

## 五、常见失效模式

- [ ] 结构件疲劳断裂
- [ ] 紧固件松动
- [ ] 焊点开裂
- [ ] 元器件脱落
- [ ] 接插件接触不良
