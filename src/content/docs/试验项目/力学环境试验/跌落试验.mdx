# 跌落试验

## 一、测试目的

跌落试验模拟产品在实际使用、装卸和运输过程中可能遇到的**非正常跌落**。通过测试，可以发现产品结构设计的薄弱环节，以及包装对产品的保护性能。

## 二、适用范围

适用于移动终端、便携式设备、包装箱、零部件及整体产品。

## 四、试验条件选择

### 1. 跌落高度

根据产品重量或实际使用场景确定：
- **&lt; 2kg**：1000mm, 1200mm
- **2-10kg**：800mm, 1000mm
- **> 10kg**：根据标准规定递减

### 2. 跌落表面

- 混凝土平面
- 钢板
- 木板

### 3. 跌落姿态

- **面跌落**：底面、顶面、侧面
- **棱跌落**：受力关键棱
- **角跌落**：最易受损的角

## 五、试验程序

1. **样品准备**：检查外观及功能。
2. **设定高度**：调整跌落试验机至预定高度。
3. **定位投放**：确保样品以规定的姿态自由跌落。
4. **重复操作**：按计划完成所有方向的跌落。
5. **结果检查**。

## 六、评定方法

- [ ] 结构检查：外壳开裂、卡扣脱落、内部零件松动或损坏
- [ ] 功能检查：产品是否能正常开机、显示、按键等功能是否正常
- [ ] 包装检查：包装材料是否起到应有的缓冲保护作用

## 七、注意事项

1. **自由落体**：跌落过程中不应受到任何外力干扰，确保是自由落体。
2. **温湿度**：某些材料（如塑料）在低温下变脆，必要时需在特定温度后立即测试。
3. **安全性**：对于带电池的产品，跌落可能引起短路或起火，需在防爆环境下进行。
