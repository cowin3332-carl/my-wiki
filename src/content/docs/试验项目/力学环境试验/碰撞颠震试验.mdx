# 碰撞颠震试验

## 一、测试目的

碰撞试验/颠震试验用于评估产品在**重复冲击、颠震环境**下的适应性，检验产品结构耐受重复冲击的能力。碰撞主要针对医用电器等产品，颠震主要针对舰船电子/军用设备。

## 二、核心标准

| 标准号 | 标准名称 |
|--------|---------|
| GB/T 14710 第11.8章 | 医用电器 碰撞试验 |
| GJB 4.8-1983 | 舰船电子设备环境试验 颠震试验 |
| GJB 150.18A-2009 | 军用装备实验室环境试验 第18部分：冲击试验 (含碰撞程序I、II) |

## 三、试验类型

| 类型 | 波形 | 典型参数 | 适用对象 |
|------|------|---------|---------|
| 碰撞 (医用) | 半正弦/后峰锯齿 | 载荷 ≤5000kg | 医用电器 |
| 颠震 (舰船/军用) | 半正弦波 | 加速度 5~1500 m/s²，脉宽 0.3~30ms，载荷 ≤16000kg | 舰船电子设备、军用设备 |


## 四、碰撞 vs 颠震 vs 冲击 参数对比

| 参数项 | 碰撞 (医用 GB/T 14710) | 颠震 (舰船 GJB 4.8) | 标准冲击 (GB/T 2423.5) |
|--------|------------------------|---------------------|----------------------|
| 波形 | 半正弦/后峰锯齿 | 半正弦波 | 半正弦/后峰锯齿 |
| 最大加速度 | 由载荷决定 | 5~1500 m/s² | ≤500 m/s² |
| 脉冲宽度 | 未明确 | 0.3~30 ms | 3~30 ms |
| 最大载荷 | 5000 kg | 16000 kg | 5000 kg |
| 速度变化量 Δv | 未明确 | 未明确 | ≤3.44 m/s |
| 重复次数 | 通常 1000~4000 次 | 按标准 | 3 次/向/轴 |

## 五、常见失效模式

- [ ] 结构件疲劳断裂
- [ ] 紧固件松动
- [ ] 焊点开裂
- [ ] 元器件脱落
- [ ] 功能异常
